About this guide

This document records how each peer-to-peer fundraising screen behaves, in plain English, one screen at a time.

It is written during an audit. A screen is added to this guide only after its flow has been walked through and agreed. Nothing is written here from assumption.

How to read it

Every screen entry uses the same headings, so the same question is answered in the same place each time.

HeadingWhat it holds
Who it is forThe person who reaches this screen, and how they get here.
What it doesThe purpose of the screen in one or two sentences.
The flowThe agreed steps, in order, from arriving to leaving.
RulesConditions that decide what is shown or refused.
MessagesWording the user sees for success, refusal and error.
NotesAnything agreed that does not fit above.
